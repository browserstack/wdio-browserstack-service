- Removed the deprecated client-side self-healing extension. This path only ran for sessions not on BrowserStack infrastructure, where it loaded a browser extension into the local browser. Those sessions no longer get local healing: the `selfHeal` service option is still accepted but has no effect off-infra, and sessions where the extension loaded via the server-side log-data flag are affected too, whether or not `selfHeal` was set. Self-healing for sessions running on BrowserStack is unaffected — it is driven by the `browserstack.selfHeal` capability, resolved hub-side.
